# lektyra

Live or recorded speech → transcript → speakers → known voices → statements worth checking.

*lektyra* = *lekton* (Stoic logic: "what is said", the content of a statement that can be true or false) +
*ankyra* (anchor): the anchor of what was said.

Status: spike. See `docs/plans/spike-plan.md` and `docs/plans/board.md`.

```
uv sync
uv run lektyra doctor
uv run lektyra ingest <url to a live stream, a video page or a file>
```
