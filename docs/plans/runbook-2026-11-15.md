
## Costs

Words: ~$0.22 an hour (ElevenLabs). Voices: free (CPU). Claims: ~$1.8 an hour. Three shows ≈ $6.

## If something goes wrong

- The stream drops: ingest reconnects by itself (up to 20 times) and records the gap.
- The page shows an error: *Stop*, then *Start listening* again; it becomes a new video, nothing is lost.
- The server stops: `uv run lektyra ui` again; a scheduled run that was running starts again for the time left
  (a new video from that moment; the audio before is kept).
- A stream drops for good: a scheduled run starts it again (up to 3 times) while its time lasts.
